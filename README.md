# CYBORG // Cybernetic Evolution

Techfest IIT Bombay Campus Ambassador Program — **Cyborg-Themed Landing Page Development** task.

## Included
- `index.html` — semantic landing page
- `styles.css` — responsive futuristic/cyberpunk UI
- `script.js` — interactions, module switching, terminal, scan/CTA feedback
- `demo.mp4` — short demo recording generated from the finished page

## Run locally
No build step is required.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Submission
The task asks for:
1. GitHub repository link
2. Google Drive link to a short demo recording with viewer access

Upload this folder to a new GitHub repository, and upload `demo.mp4` to Google Drive with **Anyone with the link → Viewer** access. Paste the two links into the Techfest submission field.

## Design direction
The interface uses a dark obsidian base, neon cyan/violet accents, HUD/terminal details, scanlines, animated telemetry, responsive layouts, and interaction states. The visual language follows common futuristic/cyberpunk UI conventions such as dark mode, neon highlights, terminal-like typography, and modular HUD elements.
